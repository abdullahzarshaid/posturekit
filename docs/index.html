Windows / Active Directory / Wireless

Configuration posture, with the evidence.

Collect host, directory and wireless configuration with PowerShell, analyze it against transparent rules in Python, and import scanner output. No agents, no dependencies, every result traceable to its evidence.

Download the latest release View the source

Evidence first

Every finding links back to the raw collected value, so results are inspectable, not asserted.

Rule-based

Checks live in readable rule files you can audit and extend, not a black box.

No dependencies

Standard-library Python and Windows PowerShell 5.1. Nothing to install on the target.

Tested

225 Python and 97 PowerShell tests. Windows execution is documented, including its limits.

How to use it. Run the PowerShell collector on the host, analyze the output with the Python engine, and read the findings with their evidence. See the repository for setup, rules and examples.
